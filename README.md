# HairEyeColor_Dataset_Analysis

This project explores the classic **HairEyeColor** dataset — a tabular dataset that records hair color, eye color, sex, and frequency counts across a group of statistics students. The goal was to practice core data analysis and visualization techniques using Python.

The notebook covers:

- Loading and inspecting the dataset using `pydataset`
- Exploring unique values, data types, and structure with pandas
- Grouping and aggregating frequency data to understand distributions
- Visualizing hair color and eye color distributions using bar plots
- Creating a heatmap to examine the relationship between hair and eye color
- Breaking down distributions further by sex using side-by-side grouped bar charts

# Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- pydataset
